# Employee Management System (Python OOP & File Handling)

A comprehensive Python Object-Oriented Programming (OOP) system built to manage company employees, calculate dynamic payrolls, track attendance, and persist data using text file handling.

## 🌟 Key Features
- **OOP Architecture:** Parent `Employee` class with derived `FullTimeEmployee`, `PartTimeEmployee`, and `Freelancer` classes.
- **Dynamic Salary Calculation:** Considers base pay, hourly rates, project rates, attendance deductions, bonuses, and penalties.
- **File Persistence:** Automatically loads and saves employee data to `employees.txt`.
- **Complete CRUD & Search:** Add, update, search (by ID, Name, Department, Type), and delete employee records.
- **Reports & Analytics:** Generates monthly payroll summaries, average salary, and highest/lowest paid employee metrics.

## 🛠 Tech Stack
- **Language:** Python 3.x
- **Concepts:** OOP (Inheritance, Polymorphism, Encapsulation), File I/O, Data Validation, CLI Interface.
